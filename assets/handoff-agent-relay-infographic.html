Handoff Save / Load Agent 接力流程

handoff 文件不是人类摘要，而是 agent 的可执行任务入口：Save Mode 负责沉淀当前上下文，Load Mode 负责读取文件并恢复执行；source agent、target reader 与 execution type 共同决定下一步动作。

5 接力更新

更新 source / target / execution、current progress、pending tasks。
刷新 recommended first steps 和 next agent first action。
切换 target 或执行类型时，写明 reroute reason。

1模式入口

所有请求先判断 save 还是 load。只有“handoff / 交接”这类模糊词才澄清；明确恢复进度时直接读取，明确保存进度时直接写入。

mode = save | load | ask-if-ambiguous

2路由与文件定位

Save 写清 source agent、target reader 和 execution type。Load 先定位 handoff 文件；找不到、路径无效或多个候选不安全时，才询问路径。

routing = source + target + execution

3执行边界

Load 后先读 routing，再按 Next Agent's First Action 执行。任务范围由 target reader 和 execution type 限定，过期时先验证再继续。

execution follows routing + first action
