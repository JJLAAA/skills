## 绘图风格总结

### 1. 布局策略

- **自上而下层次布局**，核心节点居顶，向下逐层展开
- 同级元素采用 **等宽 flex 横排**，统一间距
- 所有层级共享同一 `max-width`，视觉重心居中对齐

### 2. 色彩体系

- **一角色一色系**：每个核心实体分配独立色系（蓝/绿/橙/紫等），贯穿其容器背景、边框、箭头、标签
- **容器用浅色渐变**（`linear-gradient` 从浅到稍深），边框用该色系的饱和色
- **组件类型用左边框色区分**：不同类别的条目各分配一个固定语义色（红/黄/绿/紫）
- 整体为 **浅色底 + 彩色点缀** 的低对比度舒适风格

### 3. 容器嵌套

- **三层嵌套结构**：彩色渐变外容器 → 白色内容卡片 → 浅灰底条目
- 外容器使用大圆角（14~16px）、内容卡片中圆角（10px）、条目小圆角（5px），层级递减
- 每个容器左上角溢出放置一个 **角色徽章**（`position: absolute; top: -13px`），纯色背景白字，标明身份

### 4. 排版规范

- **Emoji 替代 SVG icon**，降低复杂度同时保持辨识度
- 小色块方形图标（20×20px 圆角）作为 section 标题前缀
- **字号分 5 级**：页面标题 → 实体名称 → 组件标题 → 正文内容 → 标签/注释，逐级递减
- 元信息（模型、配置等）用 `inline-block` 半透明彩色底的标签式排列

### 5. 连接与流向

- 层级间用 **SVG 贝塞尔曲线箭头**连接，虚线描边 + 同色三角箭头端点
- 箭头沿路径附带文字标注，与箭头同色
- 水平流程用 **flex 横排步骤方块 + 箭头符号**，关键节点加深边框和浅色底强调

### 6. 共享与复用标记

- **虚线边框**（`dashed`）区分共享/复用组件与专属组件
- 复用项在标签上附加 `⟳` 符号和文字标记
- 底部独立设置共享组件汇总区，用虚线容器统一归纳

### 7. 信息注释区

- 底部用等宽多列 Grid 排列注释/说明卡片
- 白色卡片 + 浅阴影（`box-shadow`），彩色圆形序号
- 卡片内包含 `monospace` 字体的流程描述块，用对应色系浅底边框包裹

### 8. 一句话概括

> **浅色渐变容器 + 白色内容卡片 + 语义化色彩分角色 + 虚实线区分专属/共享 + Emoji 图标 + 层次递减圆角**的信息密度适中、高可读性分层架构图风格。
