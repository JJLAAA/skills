# 证据评估标准 & 缺口分析清单

## 一、来源可信度评分矩阵

对每条证据的来源进行可信度评分（1-5 分）。

### 基础可信度

| 来源类型 | 基础分 | 说明 |
|---|---|---|
| 学术期刊（同行评审） | 5 | 经过同行评审的研究论文、系统综述、Meta 分析 |
| 官方报告 / 统计数据 | 4 | 政府机构、国际组织、行业监管机构发布的报告 |
| 权威媒体 | 3 | 有事实核查流程的主流媒体（Reuters, AP, BBC 等） |
| 专家评论 / 博客 | 2 | 领域专家的个人观点、技术博客、会议演讲 |
| 一般网站 / 论坛 | 1 | 未经验证的网站、社交媒体、匿名论坛 |

### 加分条件（每项 +0.5，上限 5 分）

- 发表于近 2 年内（时效性强）
- 包含原始数据或可复现的方法论
- 被多个独立来源交叉引用
- 作者在该领域有公认的专业资质
- 来自多个独立机构的协作研究

### 减分条件（每项 -0.5，下限 1 分）

- 发表超过 5 年且领域变化快
- 存在明显的利益冲突或赞助偏见
- 缺乏方法论描述或数据来源
- 仅有单一来源支持，无法交叉验证
- 包含明显的逻辑谬误或数据错误

### 最终可信度等级

| 分数范围 | 等级 | 标记 |
|---|---|---|
| 4.0 - 5.0 | 高可信度 | ★★★ |
| 2.5 - 3.9 | 中可信度 | ★★ |
| 1.0 - 2.4 | 低可信度 | ★ |

## 二、缺口分析清单

对收集到的证据进行五维缺口检查。每个维度下列出具体检查项，并对发现的缺口进行分级。

### 缺口严重度分级

| 级别 | 含义 | 行动 |
|---|---|---|
| CRITICAL | 核心子问题缺乏可靠证据，或存在未解决的重大矛盾 | 必须在下一轮迭代中定向搜索填补 |
| NOTABLE | 有一定证据但不够充分，或仅有单一来源 | 如果迭代预算允许，应尝试填补 |
| ACCEPTABLE | 证据基本充分，仅有边缘细节缺失 | 在报告中注明即可，无需额外搜索 |

### 维度 1：覆盖缺口（Coverage）

检查所有子问题是否都有证据支撑。

- [ ] 每个子问题至少有 2 条独立证据支持
- [ ] 没有子问题完全缺乏证据（→ CRITICAL）
- [ ] 没有子问题仅有 1 条低可信度证据（→ CRITICAL）
- [ ] 关键术语和概念都有明确定义或解释

### 维度 2：时效缺口（Timeliness）

检查证据的时间分布是否合理。

- [ ] 核心主张有近 2 年内的证据支持
- [ ] 如果领域变化快（技术、政策等），没有仅依赖 3 年以上旧数据的情况（→ CRITICAL）
- [ ] 已识别并标注可能已过时的信息
- [ ] 如有重大近期发展（政策变更、新研究），已纳入分析

### 维度 3：矛盾缺口（Contradiction）

检查证据之间的一致性。

- [ ] 已识别所有相互矛盾的主张
- [ ] 矛盾已尝试解释（方法差异、样本差异、时间差异等）
- [ ] 无法解释的重大矛盾已标记（→ CRITICAL）
- [ ] 没有选择性忽略不利证据的情况

### 维度 4：深度缺口（Depth）

检查分析是否足够深入。

- [ ] 不仅有"是什么"，还有"为什么"和"怎么样"
- [ ] 关键数据有具体数字而非模糊描述
- [ ] 因果关系主张有机制解释或实验证据支持
- [ ] 核心论点有足够的论据链条，而非仅有结论（→ NOTABLE if missing）

### 维度 5：视角缺口（Perspective）

检查是否考虑了多元视角。

- [ ] 包含支持方和反对方的观点
- [ ] 考虑了不同利益相关者的立场
- [ ] 没有仅从单一地域/文化/学派视角分析的情况（→ NOTABLE）
- [ ] 少数派或非主流但有依据的观点已被提及

## 三、证据块结构

每条收集到的证据应结构化为以下格式（供内部追踪）：

```
- claim: [具体主张]
- source_url: [来源 URL]
- source_type: [学术期刊 | 官方报告 | 权威媒体 | 专家评论 | 一般网站]
- confidence: [1-5 分]
- date: [发布日期]
- supports_subquestion: [对应的子问题编号]
- cross_validated: [true/false — 是否有其他独立来源佐证]
```
